# Astra Dashboard

Minimalist React dashboard for cryptomining detection system.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Dashboard runs on http://localhost:5173

## Configuration

Set API URL in `.env`:
```
VITE_API_URL=http://localhost:3000
```

## Build

```bash
npm run build
```

Output in `dist/` directory.
